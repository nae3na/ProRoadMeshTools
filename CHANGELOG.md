# Changelog

## [1.0.0] - 2026-09-27

- Added ProRoad mesh collider setup for individual roads and parent hierarchies.
- Added the window at **Tools > ProRoad Mesh Tools**, directly below ProRoad's **ObjectPlanter** submenu.
- Used action-specific button labels for collider and combined-mesh operations.
- Added grouped Undo support for ProRoad and ObjectPlanterLine setup operations.
- Added individual and batch mesh normal recalculation.
- Deduplicated unreadable shared meshes before reporting and skipping them.
- Added ObjectPlanterLine combined-mesh setup.
- Set Unity 6 as the minimum supported Unity version.
- Added a Japanese README.
