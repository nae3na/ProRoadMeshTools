# ProRoad Mesh Tools

ProRoad Mesh Tools adds post-processing operations for meshes generated by ProRoad and its bundled ObjectPlanter tools.

## Features

- Add mesh colliders to generated ProRoad meshes.
- Assign a physics material while setting up roads.
- Recalculate generated road mesh normals individually or in batches.
- Prepare combined ObjectPlanterLine output.

See [Installation](installation.md), [Usage](usage.md), and [Manual verification](verification.md) for setup, operation, and release-check details.
