# Installation

## Requirements

- Unity 6 or later
- An existing licensed copy of [ProRoad](https://assetstore.unity.com/packages/tools/terrain/proroad-119351) imported into the target project

ProRoad and ObjectPlanter are not distributed with this package.

ProRoad is no longer available for purchase from the Unity Asset Store. The link above is provided only as a product reference. This package is intended for users who already have a valid ProRoad license.

## Install from Git

1. Import an existing licensed copy of ProRoad into the Unity project.
2. Open Unity Package Manager.
3. Select **Add package from git URL**.
4. Enter `https://github.com/nae3na/ProRoadMeshTools.git`.

The package expects the `CP.ProRoad.ProRoad` and `CP.ObjectPlanter.ObjectPlanterLine` types supplied by ProRoad to be available.
