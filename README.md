# ProRoad Mesh Tools

[![Readme_JA](https://img.shields.io/badge/README-日本語版-blue)](./README_JA.md)

Unity Editor tools for additional mesh processing in ProRoad workflows.

## Requirements

- Unity 6 or later
- An existing licensed and imported copy of [ProRoad](https://assetstore.unity.com/packages/tools/terrain/proroad-119351)

ProRoad and ObjectPlanter are not included in this package.

ProRoad is no longer available for purchase from the Unity Asset Store. The link above is provided only as a product reference. This package is intended for users who already have a valid ProRoad license.

## Installation

Import an existing licensed copy of ProRoad into the Unity project first, then add this repository from Unity Package Manager using its Git URL:

```text
https://github.com/nae3na/ProRoadMeshTools.git
```

## Usage

Open `Tools > ProRoad Mesh Tools` in the Unity Editor. The item appears directly below ProRoad's **ObjectPlanter** submenu.

The window provides the following operations:

- Add a `MeshCollider` to generated ProRoad meshes and optionally assign a physics material.
- Recalculate normals for meshes generated by one ProRoad or all ProRoad components under a parent.
- Prepare combined ObjectPlanterLine output by keeping the generated combined object active and adding a `MeshCollider`.

Run the normal recalculation again after regenerating a road with ProRoad.

ProRoad generation can deform Terrain when `Do Not Modify Terrain` is disabled. ProRoad Mesh Tools does not generate roads or modify Terrain, and its Undo operations must not be used as a rollback for Terrain deformation.

## Compatibility

The package targets Unity 6 or later and uses `PhysicsMaterial`.
